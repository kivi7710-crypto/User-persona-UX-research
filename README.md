# User-persona-UX-research
A beginner-friendly UX research project exploring user personas, research methods, journey mapping and pain-point identification.
👤 User Persona – UX Research Case Study

📌 Project Overview

This project explores the importance of user research in the UI/UX design process.

It demonstrates how user personas, research methods and journey mapping help designers understand user needs, goals, behaviours and pain points before developing a digital product.

The project uses a fictional food delivery application called QuickBite as a practical example.

🎯 Project Objectives

- Understand the fundamentals of user research.
- Explore different research methods.
- Create a user persona.
- Identify user goals and frustrations.
- Develop a user journey map.
- Identify pain points.
- Define a clear problem statement.
- Suggest user-centred design improvements.

🔍 Research Methods Covered

1. User Interviews
2. Surveys
3. Observation
4. Analytics
5. Competitor Analysis

👤 User Persona

Name: Ananya Sharma

Age: 22

Occupation: College Student

Location: Chennai

Product: QuickBite Food Delivery App

The persona is a hypothetical example created to demonstrate the UX research process. It is not based on verified participant interviews.

Goals

- Order food easily.
- Find affordable meals.
- Track deliveries.
- Save time.

Pain Points

- Complicated checkout.
- Unclear delivery information.
- Difficulty comparing prices.
- Limited payment choices.

🗺️ User Journey Map

The journey map covers six stages:

1. Opens the application.
2. Searches for food.
3. Compares restaurants.
4. Adds food to cart.
5. Completes checkout.
6. Tracks the order.

Each stage considers user actions, thoughts, emotions, pain points and improvement opportunities.

💡 Design Opportunities

- Simple navigation.
- Clear pricing information.
- Easy checkout process.
- Multiple payment options.
- Real-time order tracking.
- Clear delivery information.
